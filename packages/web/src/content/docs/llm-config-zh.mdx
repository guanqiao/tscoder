## 配置文件位置

OpenCode 支持多个配置文件位置，按优先级排序：

### 1. 项目配置文件（推荐）


### 2. 全局配置文件

在用户主目录下的 `.config/opencode/` 目录中：

- **Windows**: `C:\Users\你的用户名\.config\opencode\opencode.json`
- **macOS**: `~/.config/opencode/opencode.json`
- **Linux**: `~/.config/opencode/opencode.json`

### 3. 环境变量指定

通过 `OPENCODE_CONFIG` 环境变量指定自定义路径：

```bash

# macOS/Linux
```


## CA 证书配置

### 什么是 CA 证书�?

CA（Certificate Authority）证书用于验�?HTTPS 连接的服务器身份。OpenCode 要求所�?LLM 连接都必须使用自定义 CA 证书，以确保连接安全�?

### 获取 CA 证书

#### 方法 1：从系统导出

**macOS:**
```bash
# 导出系统证书
security find-certificate -a -p /System/Library/Keychains/SystemRootCertificates.keychain > ~/.certs/system-ca.pem
```

**Linux (Ubuntu/Debian):**
```bash
# 复制系统证书
cp /etc/ssl/certs/ca-certificates.crt ~/.certs/system-ca.pem
```

**Windows:**
```powershell
# 使用 PowerShell 导出证书
Get-ChildItem -Path Cert:\LocalMachine\Root | ForEach-Object {
    "-----BEGIN CERTIFICATE-----" | Out-File -Append -FilePath "$env:USERPROFILE\.certs\system-ca.pem"
    [Convert]::ToBase64String($_.RawData, 'InsertLineBreaks') | Out-File -Append -FilePath "$env:USERPROFILE\.certs\system-ca.pem"
    "-----END CERTIFICATE-----" | Out-File -Append -FilePath "$env:USERPROFILE\.certs\system-ca.pem"
}
```

#### 方法 2：从服务提供商获�?

- **OpenAI**: 可以�?OpenAI 官方文档或支持团队获�?
- **Anthropic**: �?Anthropic 官方文档获取
- **自托�?*: 使用自签名证书时，导出对应的 CA 证书

#### 方法 3：使�?Let's Encrypt 证书

如果使用 Let's Encrypt 证书的服务：


### 证书路径说明

- **绝对路径**: `/home/user/.certs/ca.pem` �?`C:\Users\User\.certs\ca.pem`

## 常见问题
