## 重构计划

### 目标
将所有的远程加载功能重构为本地加载，包括：
1. Well-Known 远程配置 → 本地配置
2. Skills 远程下载 → 本地 Skills
3. MCP Remote 服务器 → 仅保留 Local

### 修改文件清单
1. `packages/opencode/src/config/config.ts` - 移除 well-known fetch 逻辑
2. `packages/opencode/src/skill/discovery.ts` - 移除远程下载逻辑
3. `packages/opencode/src/mcp/index.ts` - 移除 remote 类型处理
4. `packages/opencode/src/config/config.ts` - 移除 McpRemote Schema

### 本地目录结构
```
~/.config/opencode/
├── wellknown/          # 原远程 well-known 配置
│   └── {source}.json
├── skills/             # 本地 skills
│   └── {skill}/SKILL.md
└── mcp/                # MCP 配置（仅 local）
```

### 实施步骤
1. 重构 well-known 配置加载
2. 重构 skills 发现机制
3. 重构 MCP remote 支持
4. 测试验证
