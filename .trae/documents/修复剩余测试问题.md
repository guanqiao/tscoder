## 修复计划

### 1. Snapshot 测试失败问题
**根本原因分析：**
- `Snapshot.track()` 返回 `undefined` 因为 `Instance.project.vcs !== "git"`
- 测试使用了 `git: true` 创建临时目录，但 `Project.fromDirectory()` 可能因为 `git rev-list --max-parents=0 --all` 在空仓库中返回空而设置 `vcs: undefined`

**修复方案：**
- 修改 `test/fixture/fixture.ts` 中的 `bootstrap()` 函数，确保创建带有实际提交的非空 git 仓库
- 或者在 `test/snapshot/snapshot.test.ts` 中设置 `process.env.OPENCODE_FAKE_VCS = "git"`

### 2. Windows 路径问题 (apply_patch)
**根本原因分析：**
- 测试期望相对路径 `nested/new.txt`，但实际返回绝对路径 `C:\Users\...\nested\new.txt`

**修复方案：**
- 修改 `test/tool/apply_patch.test.ts`，使用 `path.relative()` 或将期望值改为绝对路径

### 3. LSP 客户端测试超时
**根本原因分析：**
- 测试完成后的流关闭问题

**修复方案：**
- 添加适当的清理逻辑或增加超时时间
